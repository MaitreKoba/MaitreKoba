### Ce que je fais

**Les bots Kobayashi.** Une plateforme qui fait tourner plusieurs bots Discord depuis un seul projet, chacun avec son rôle : Kanna pour les membres (niveaux, jeux, profils), Tohru pour le staff (tickets, modération, formulaires du site), Ilulu pour la protection du serveur, Cloé pour le vocal. Tout se règle depuis Discord avec `/config`, sans toucher au code.

**Béatrice.** Mon assistante IA personnelle, auto-hébergée. Elle parle, gère mes mails et mon agenda, et passe d'un fournisseur d'IA à l'autre quand un quota tombe. Elle a aussi son agent de code dans le terminal, KobaClaude.

**KobaAntiScam.** Une appli Android qui filtre les appels et SMS d'arnaque. [Voir le dépôt](https://github.com/MaitreKoba/KobaAntiScam)

### Avec quoi

Node.js et discord.js pour les bots, Python pour les agents IA, SQLite et MySQL pour les données, Electron pour les applis de bureau.
